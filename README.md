# Solar Load Calculator AI App

## Overview
This project automates electricity bill processing using OCR and AI.

## Features
- Upload JPG/PNG/PDF bills
- Extract electricity data
- Generate Excel reports
- Solar load recommendation

## Tech Stack
- Python
- OCR
- Flask
- Pandas
- HTML/CSS
